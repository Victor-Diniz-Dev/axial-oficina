# AXIAL — oficina independente

Site institucional em React + Vite para uma oficina mecânica fictícia, criado como peça de portfólio.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

O conteúdo editável está concentrado em `src/data/company.js`. As imagens foram salvas localmente em `public/images` a partir de fotos gratuitas sob a licença Unsplash.
